Endstep Tracker

Records your endstep.cc matches in Safari: opponent's cards, play/draw, mulligans, results.

Enregistre tes matchs endstep.cc dans Safari : cartes adverses, play/draw, mulligans, résultats.

  1. Turn the extension on.Active l’extension. Settings › Apps › Safari › Extensions › Endstep Tracker: turn on “Allow Extension”. Réglages › Apps › Safari › Extensions › Endstep Tracker : active « Autoriser l’extension ».
  2. Allow endstep.cc.Autorise endstep.cc. On the same page, set endstep.cc to “Allow”. On “Ask”, it misses parts of your matches. Sur la même page, mets endstep.cc sur « Autoriser ». Sur « Demander », il rate des bouts de tes matchs.
  3. Play.Joue. On endstep.cc in Safari, the button left of the address opens Endstep Tracker and its dashboard. Not in endstep added to the Home Screen: extensions don’t run there. Sur endstep.cc dans Safari, le bouton à gauche de l’adresse ouvre Endstep Tracker et son tableau de bord. Pas dans endstep ajouté à l’écran d’accueil : les extensions n’y fonctionnent pas.

Tes matchs restent sur cet iPhone. Pour les retrouver sur un autre appareil : « Exporter une sauvegarde » ici, puis « Importer une sauvegarde » là-bas (menu Données du tableau de bord).
